# Roms Download Helper

Un script en Python que busca, filtra y descarga múltiples archivos ROM en paralelo usando `aria2c`.

## 🎮 Consolas soportadas

- PlayStation 1 (`psx`)
- PlayStation 2 (`ps2`)
- Nintendo GameCube (`gamecube`)
- Nintendo 64 (`n64`)
- Sega Saturn (`saturn`)

## 📦 Requisitos

- Python 3.8+
- `aria2c` instalado:
  ```bash
  # Ubuntu/Debian
  sudo apt install aria2

  # macOS (Homebrew)
  brew install aria2

## Uso
Ejecuta el script con:

    python3 main.py

Luego, sigue las indicaciones interactivas para:

 - Seleccionar consola. 
 - Filtrar por nombre de juego. 
 - Excluir términos (ej. demo, beta). 
 - Filtrar por idioma (ej. es, en). 
 - Confirmar y descargar.

⚠️ Nota legal: Asegúrate de cumplir con las leyes de derechos de autor de tu país. Este script es solo para uso educativo y con ROMs de las que posees el juego físico.
